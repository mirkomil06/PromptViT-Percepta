# 📦 Dataset Directory

This folder stores local copies of datasets used in the project.  
Due to size limits, **datasets are not included in the GitHub repo**.

## Structure
- `cub200/` — CUB-200-2011 fine-grained bird dataset  
- `cars/` — Stanford Cars dataset  
- `flowers/` — Oxford 102 Flowers dataset  

Each dataset includes pre-split folders for training, validation, and testing.  
Download links are listed in the main [README.md](../README.md).
